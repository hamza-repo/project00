# Why Git Makes Development Easier

## Safeguarding Code
uses commit as a permanent snapshot of your project. If you write bad code or accidentally delete a critical file, you don’t need to rewrite anything.
You can instantly revert your codebase to the exact second it last worked flawlessly.

## Tracking History

	Who changed it → stored as the commit author
	When → stored as the commit date/time
	What changed → Git compares that commit’s snapshot with the previous commit

## Enables team collaboration
 Git allows multiple developers to work on the same project without constantly overwriting each other's work.
 Developers can pull work or work on separate branches and later merge their changes together.
 A branch is a separate line of development inside the same Git repository.
